## 🚀 Overview
- **Name**: Muhammed Safvan
- **Title**: Sales & Marketing Specialist
- **Expertise**: Sales & Client Acquisition, Performance Marketing, Content Marketing, Social Media Management, Video Editing, Marketing Consultation, Personal & Company Branding.

## 📂 Project Structure
- `index.html` — Main website structure and content
- `styles.css` — Modern dark theme styling, typography, and responsive grid layouts
- `script.js` — Scroll reveal animations powered by IntersectionObserver
- `assets/` — Profile photo, personal branding infographics, case study dashboards, and client logos
- `server.ps1` — Lightweight PowerShell local HTTP server

## 💻 Running Locally
Open `index.html` directly in your browser, or run the local preview server:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit [http://localhost:3000/](http://localhost:3000/).
